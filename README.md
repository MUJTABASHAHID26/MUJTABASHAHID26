## `> cat system-design.md`

I treat system design as a skill to practice, not just something to read about. My notes and write-ups cover:

- Scalability: horizontal scaling, load balancing, stateless services
- Caching strategies: cache-aside, write-through, TTLs, invalidation
- Data: SQL vs NoSQL trade-offs, indexing, sharding, replication
- Reliability: rate limiting, retries, idempotency, graceful degradation
- Communication: REST, pub/sub, async processing, queues
